# apps/bale-bot — ربات پیام‌رسان بله

آداپتر نازک مشابه `telegram-bot`: پیام کاربر → Backend API (`/v1/rag/query` یا `/v1/apcs/query`) → پاسخ + Citation.

## وضعیت
اسکلت برنامه‌ریزی‌شده (فاز کانال‌های پیام‌رسان).

## پیش‌نیاز
- توکن ربات از پنل توسعه‌دهندگان بله
- `BACKEND_URL` یکسان با تلگرام

## اصول
- بدون منطق دامنه داخل ربات
- همه پاسخ‌های مالیاتی از API Gateway
- لاگ و rate-limit در Gateway
